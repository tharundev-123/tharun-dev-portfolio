3. **Engineering Case Studies**: In-depth editorial spreads for featured projects:
   - *Digital Healthcare BMI & Diet Planner* (Nimbus Project)

4. **Live GitHub Open-Source Feed**: Real-time stats (repositories, stars, followers) and curated repository cards fetched dynamically from `github.com/tharundev-123`.
5. **Technical Disciplines & Capabilities**: Clean typographic matrix categorizing Programming, Cloud Infrastructure, Developer Tooling, and Active Horizons.

8. **Archival Audio-Visual Intro Tape**: Optional spoken intro player modal with live subtitle tracking, preserving authentic audio (`voice.mp3`) and video (`intro_video.mp4`).
9. **Command Palette (`Cmd+K` or `/`)**: Quick keyboard search overlay for rapid section navigation.
10. **Persistent Archival Assistant (TD.AI)**: Unobtrusive bottom-right query bot answering questions on projects, background, and credentials.
11. **Subtle Atmospheric Canvas**: Lightweight Three.js particulate field drifting gently without visual noise or neon distractions.

## 🛠️ Technology Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), CSS3 with CSS Custom Properties.
- **Graphics & CDNs**: Three.js (r128), Lucide Icons CDN.
- **Fonts**: Google Fonts (`Cormorant Garamond`, `Manrope`, `IBM Plex Mono`).
- **Form Delivery**: FormSubmit AJAX API.

## 🚀 Local Development Setup

To serve locally:
```bash
# Using Python built-in server
python -m http.server 3000

# Or using Node.js serve
npx -y serve -l 3000
```
Open `http://localhost:3000` in your web browser.
